目前代码中能够确认的功能
1. 网页上传 IPA
使用 Flask 提供中文 Web 界面，填写应用信息、选择平台和 IPA 文件后执行上传。


2. App Store Connect API 鉴权
使用 API Key 的 .p8 私钥、Issuer ID 和 Key ID 生成 ES256 签名 JWT，并查询账号下的应用。


3. 自动识别 IPA 版本信息
解析 IPA 中主应用的 Info.plist，读取 Bundle ID、版本号和 Build 号，并在表单信息不匹配时以 IPA 内的数据为准。


4. 分段上传与提交
创建 Build Upload 和 Build Upload File 资源，根据 Apple 返回的上传操作分段传输 IPA，再执行提交操作。


5. 日志与问题排查
记录请求 ID、API 状态码、执行耗时和错误信息，方便定位上传失败的原因。


6. 命令行与 Web 两种入口
核心上传模块提供 CLI 操作，同时通过 Flask 暴露网页接口，方便不同使用习惯的开发者使用。



它解决了什么问题？
常见的 iOS 构建上传流程涉及应用 ID、API 密钥、版本号、构建号、IPA 文件以及上传状态等多个步骤。这个项目把其中的 API 调用和文件上传流程整合起来，减少手动操作。
它的主要卖点是：
- 不局限于 macOS 本地 GUI 操作，可在具备合适 Python 环境的 Linux 服务器上运行。
- 可以通过网页操作，不必每次手动拼接命令。
- 自动从 IPA 读取版本和 Build 信息，减少表单填写错误。
- 有结构化日志，方便服务器部署后的问题排查。
需要注意： 代码结构具备上述功能，但我没有使用真实的 Apple 开发者账号完成端到端上传测试，因此不能据此保证所有平台、所有文件大小和所有 App Store Connect 账号都能一次上传成功。项目也不是 Xcode 编译工具；它负责的是构建产物上传流程。
